### Projects

Self-hosted multi-agent AI, civic-data platforms, and production web tools.

#### AI / Infrastructure

- **[NIVI Hub](https://github.com/idahofidelity/nivi-hub)** — self-hosted multi-agent AI infrastructure. Agent access via Telegram and Discord. Public architecture write-up; live stack stays private.

#### Civic Tech (Idaho Fidelity Foundation)

- **[Idaho Ledger](https://idaholedger.com)** — fact-only bill and vote tracker for the Idaho Legislature.
- **[Idaho Scorecard](https://idahoscore.com)** — scoring platform for Idaho elected officials, including judges and sheriffs.
- **[Idaho Courtwatch](https://github.com/idahofidelity/courtwatch)** — statewide judge rating system from public court records. Collector is private while data is validated.
- **[Crime Clarity](https://github.com/idahofidelity/crime-clarity)** — Idaho arrestee race vs. ethnicity pipeline (FBI NIBRS 49/50) with county-vs-statewide reconciliation. [Live](https://idahofidelity.github.io/crime-clarity/).
