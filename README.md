### Projects

Self-hosted multi-agent AI, civic-data platforms, and production web tools.

**All links:** [idahofidelity.github.io](https://idahofidelity.github.io/) · **Project details:** [idahofidelity.github.io/projects](https://idahofidelity.github.io/projects/)

#### AI / Infrastructure

- **[NIVI Hub](https://github.com/idahofidelity/nivi-hub)** — self-hosted multi-agent AI infrastructure. Agent access via Telegram and Discord. Public architecture write-up; live stack stays private.

#### Civic Tech (Idaho Fidelity Foundation)

- **[Idaho Ledger](https://idaholedger.com)** — fact-only bill and vote tracker for the Idaho Legislature.
- **[Idaho Scorecard](https://idahoscore.com)** — scoring platform for Idaho elected officials, including judges and sheriffs.
- **[Idaho Courtwatch](https://github.com/idahofidelity/courtwatch)** — statewide judge rating system from public court records. Collector is private while data is validated.
- **[Crime Clarity](https://github.com/idahofidelity/crime-clarity)** — Idaho arrestee race vs. ethnicity pipeline (FBI NIBRS 49/50) with county-vs-statewide reconciliation. [Live](https://idahofidelity.github.io/crime-clarity/).
- **[Idaho Homeless Tracker](https://github.com/idahofidelity/idaho-homeless-tracker)** — Idaho homeless-related news and community reports, city-level, not person-level. [Live](https://idahofidelity.github.io/idaho-homeless-tracker/).
- **[American CDL Incident Tracker](https://github.com/idahofidelity/american-cdl-incident-tracker)** — national commercial-vehicle incident database (FARS / FMCSA / NTSB), human-reviewed publishes. [Live](https://idahofidelity.github.io/american-cdl-incident-tracker).
- **[Failure Watch](https://github.com/idahofidelity/failure-watch)** — infrastructure tracker: US industrial failures, refineries, chemical plants, spills, with AI-scored source neutrality. [Live](https://idahofidelity.github.io/failure-watch/).

- **[Rental Finder](https://github.com/idahofidelity/rental-finder)** — North Idaho rental search, calculator, and tracker. [Live](https://rental-finder-mu.vercel.app).
- **[Land Tracker](https://github.com/idahofidelity/land-tracker)** — Kootenai County vacant land listing tracker. [Live](https://land-tracker-opal.vercel.app).
